# Developer documentation

This folder contains documentation that's mostly useful for developing violet, but may also be useful for understanding certain technical details about violet. There's also some more broad design docs that aren't directly applicable to end-users, but explains why violet is the way it is.

Information in this folder may be interesting, but is not by any means required reading material for end-users of violet.
