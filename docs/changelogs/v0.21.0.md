## Added

* Theme (default): added a changelog `type` to make it easier to write changelogs. Both `page_list` and `single_page` is offered.
* Theme (default): Added `data.release-url` for the aforementioned changelog type to make it possible to auto-generate links to releases.
* Added the `_macros` folder, which allows defining user-defined functions that are available globally ([#51](https://codeberg.org/LunarWatcher/violet/issues/51))
  * See [the macro documentation](/templating/Macros.md) for more info
* Theme assets now support templates
  * Previously, theme files were unconditionally copied directly to the output directory without any processing, which means no template processing took place in theme files even though asset files have supported this for ages.

## Changed

* Updated to iris [v0.4.0](https://lunarwatcher.codeberg.page/iris/changelogs/v0.4.0.html) (highlights: `{% macro %}` support, `append(list, newItem)`, misc. bugfixes)
* Added `<hr/>` when footnote headers are disabled ([#53](https://codeberg.org/LunarWatcher/violet/pulls/53))

## Fixed

* Violet no longer produces a garbled error message when `violet.json` is missing
* Added better error messages for JSON deserialization errors in frontmatter
